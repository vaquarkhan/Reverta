Error codes sit outside the MCP range.

JSON-RPC parse failures are -32700. A request that is not a 2.0 object is -32600. An unknown method is -32601. Missing MCP _meta is -32602. Application codes are outside -32768 through -32000, so they do not collide with MCP’s -32000 to -32099 band.

A finished rollback is not one of these codes. The JSON-RPC result succeeds and state is ROLLED_BACK. Argument validation covers type, enum, string length, numeric bounds, array bounds, items, required, and additionalProperties. It is a profile of JSON Schema 2020-12, not a complete validator.
