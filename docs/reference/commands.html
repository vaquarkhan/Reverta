The tx-engine command.

The shaded jar is mcp-tx-proxy/target/tx-engine.jar. The entrypoint is org.atp.proxy.TxEngineMain.

CommandWhat it does
demo --port 8080Serves the operations console and POST /mcp. Same process as serve.
stdioReads one JSON-RPC object per line and writes one response per line.
keysPrints a new Ed25519 public key, then the private key, both base64.
sign --kid --private --payloadSigns a manifest payload file.
replay --tx --wal-dir --sandbox --up-to-stepWalks a recorded transaction. --sandbox is required.
chaos --out file.csvWrites the recovery comparison. Parent directories are created.

Environment

VariableEffect
ATP_JDBC_URLJournal in JDBC. H2 and PostgreSQL are on the classpath of the shaded jar.
ATP_JDBC_USERJDBC user. Empty when unset.
ATP_JDBC_PASSWORDJDBC password. Empty when unset.
ATP_WAL_DIRFile journal, used only when no JDBC URL is set. Writes wal.bin and wal.anchor.

HTTP routes on the demo

  • GET / — the operations console.
  • POST /mcp — JSON-RPC. One SSE event when Accept contains text/event-stream.
  • GET /api/ledger — the hash chain wrapped as a tx/ledger result.
  • POST /api/demo/rollback — the three-step failure, transaction ui-rollback.
  • POST /api/demo/approve-setup — parks send_wire. Send {"txId":"ui-wire-1"} or omit it to reuse ui-wire.
  • POST /api/demo/decision — body {"txId","decision"} with APPROVE, REJECT, or RETRY.
